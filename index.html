Section A — Cartesian Coordinates

Every point is an ordered pair (x, y)

The horizontal x-axis and vertical y-axis cross at the origin O(0, 0). A point's position is written as (x, y) — x tells you how far left/right, y tells you how far up/down. The two axes divide the plane into 4 quadrants.

Section B — Plotting Points and Drawing a Line

Plot each point, then connect the dots

To turn a set of ordered pairs into a graph: plot every point the same way you did in Section A — over to its x-value, then up or down to its y-value. If the points come from a linear relation, joining them with a ruler always gives a perfectly straight line.

Worked example

Points (−3, −1), (0, 2), (2, 4) all come from the same relation. Plot each one, then join them in order — they line up perfectly.

If your three points don't line up, check your plotting before assuming the relation isn't linear.

Section D — Linear Functions and Linear Graphs

The Equation of a Line

Every straight-line graph can be written as an equation. Before we get into it, two quick definitions you'll need:

x-intercept — the x-coordinate of the point where a graph crosses the x-axis.
y-intercept — the y-coordinate of the point where a graph crosses the y-axis.

A linear function's equation always takes the same general form:

🔄

What is the general equation of a Straight-Line (Linear) function?

tap to reveal
y = mx + c
m is the gradient — how steep the line is, and which direction it slopes.
c is the y-intercept — the point where the line crosses the y-axis, at (0, c).
tap to hide
🔄

What does it mean for a point to "satisfy" an equation?

tap to reveal

When you substitute x = a and y = b into y = mx + c, and both sides become equal (LHS = RHS), we say the pair of values satisfies the equation.

That means the point (a, b) lies on the graph of y = mx + c.

tap to hide
✏️ Worked example — y = 3x − 4

Comparing y = 3x − 4 to y = mx + c directly:

m = 3 — the gradient
c = −4 — the y-intercept

We can check the gradient by picking two points on the line and using rise over run:

m = 62 = 3 ✓

When you substitute a pair of values x = a and y = b into an equation, and both sides come out equal, we say that pair of values satisfies the equation. This tells us the point (a, b) lies exactly on the graph of that equation.

Does the point (1, −1) satisfy y = 3x − 4? Substitute and check both sides:

LHS: y = −1 RHS: 3(1) − 4 = −1 LHS = RHS ✓ — so (1, −1) lies on the line.
✏️ Rearranging into y = mx + c form

Sometimes an equation isn't written in y = mx + c form yet — you'll need to rearrange it first before you can read off m and c.

Example: Rearrange 2y = 6x + 8.

2y = 6x + 8 Divide every term by 2: y = 3x + 4

Now it's in y = mx + c form, so we can read it straight off: m = 3, c = 4.

Everything you've covered so far

A · The origin, ordered pairs & quadrants

The origin (0, 0) is where the x-axis and y-axis cross.

An ordered pair (x, y) gives a point's exact position — x is how far left/right from the origin, y is how far up/down from the origin.

The two axes split the plane into 4 quadrants: I (+,+), II (−,+), III (−,−), IV (+,−).

B · Plotting ordered pairs

To plot a point: move to its x-value, then up/down to its y-value.

Plot each point in a set, then connect them — if they come from a linear relation, they'll always line up into a perfectly straight line.

C · Functions

A function means every input maps to exactly one output.

For f(x) = 2x + 3, putting in x = 4 always gives f(4) = 11 — never anything else.

A vertical line on a graph is NOT a function, since one x-value would give infinitely many y-values.

D · y = mx + c

Every linear equation graphs as a straight line.

m is the gradient (steepness/direction), c is the y-intercept (where it crosses the y-axis, at (0, c)).

You can substitute an x-value to find y, or substitute a y-value to find x — same equation, both directions.

If a pair of values makes both sides of the equation equal, they satisfy the equation — that point lies on the line.

If an equation isn't already in y = mx + c form, rearrange it first before reading off m and c.
