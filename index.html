Section A — Cartesian Coordinates

Every point is an ordered pair (x, y)

The horizontal x-axis and vertical y-axis cross at the origin O(0, 0). A point's position is written as (x, y) — x tells you how far left/right, y tells you how far up/down. The two axes divide the plane into 4 quadrants.

⚠️ Easy to mix up The x-coordinate always comes first, the y-coordinate always comes second — (3, 5) and (5, 3) are two completely different points, even though they use the same two numbers.

If a point hasn't moved up or down from the x-axis at all, what must its y-coordinate be?
Every point on the x-axis has moved 0 units up or down, so y = 0. E.g. (5, 0), (−2, 0).

Section B — Plotting Points and Drawing a Line

Plot each point, then connect the dots

To turn a set of ordered pairs into a graph: plot every point the same way you did in Section A — over to its x-value, then up or down to its y-value. If the points come from a linear relation, joining them with a ruler always gives a perfectly straight line.

Worked example

Points (−3, −1), (0, 2), (2, 4) all come from the same relation. Plot each one, then join them in order — they line up perfectly.

⚠️ Watch out If your three points don't line up, check your plotting before assuming the relation isn't linear — a single misplaced point is almost always the cause.

If you accidentally plotted one point in the wrong quadrant, what would happen when you tried to draw the straight line through all your points?

If every other point comes from the same equation and lines up perfectly, what happens when one point doesn't belong there?
A point plotted in the wrong quadrant almost certainly doesn't satisfy the equation — so it won't sit on the same line as the rest. You'd see a visible kink or an outlier point, which is actually a useful way to catch plotting mistakes.

A · The origin, ordered pairs & quadrants

The origin (0, 0) is where the x-axis and y-axis cross.

An ordered pair (x, y) gives a point's exact position — x is how far left/right from the origin, y is how far up/down from the origin.

The two axes split the plane into 4 quadrants: I (+,+), II (−,+), III (−,−), IV (+,−).

A point with x = 0 sits exactly on the y-axis; a point with y = 0 sits exactly on the x-axis.

A · Plotting & reading individual points

To plot any single point: count left/right from the origin for x, then up/down for y.

Reading coordinates off a diagram works in reverse — count how far the point has moved from the origin in each direction.

The Coordinate Hunt activity practised this both ways: writing an ordered pair for a given item, and naming the item at a given ordered pair.

B · Plotting ordered pairs

To plot a point: move to its x-value, then up/down to its y-value.

Plot each point in a set, then connect them — if they come from a linear relation, they'll always line up into a perfectly straight line.
